# ملوسک — راهنمای دیپلوی رایگان

این پکیج یک سایت خبری کاملاً رایگان است که هر ساعت خودش را به‌روزرسانی می‌کند:

- `index.html` — خود سایت (فقط فایل `data/news.json` را می‌خواند، هیچ درخواست شبکه‌ای به سرویس خارجی نمی‌زند)
- `data/news.json` — داده‌های اخبار (یک نسخهٔ اولیه از قبل داخلش هست)
- `scripts/fetch_news.py` — اسکریپتی که فیدهای RSS را می‌خواند و `data/news.json` را بازنویسی می‌کند
- `.github/workflows/update-news.yml` — تنظیمات GitHub Actions که هر ساعت اسکریپت بالا را اجرا می‌کند

## چرا این روش؟
مرورگر معمولاً اجازهٔ خواندن مستقیم RSS از دامنه‌های دیگر را نمی‌دهد (محدودیت CORS).
راه‌حل: واکشی از سمت سرور (GitHub Actions) انجام می‌شود، نه از مرورگر کاربر — پس این مشکل اصلاً پیش نمی‌آید.

## مراحل دیپلوی (حدود ۵ دقیقه، کاملاً رایگان)

1. یک حساب GitHub بسازید (اگر ندارید): github.com
2. یک ریپازیتوری جدید بسازید، مثلاً به نام `malusak` — گزینهٔ Public را انتخاب کنید (برای Public بودن، دقایق اجرای Actions کاملاً نامحدود و رایگان است).
3. تمام فایل‌های این پکیج را در همان ساختار پوشه‌ای که هست، در ریپازیتوری آپلود کنید (می‌توانید از دکمهٔ «Add file → Upload files» در وب‌سایت GitHub استفاده کنید؛ پوشه‌ها را هم می‌شود مستقیم درگ‌ اند دراپ کرد).
4. به تب **Settings → Pages** بروید. زیر «Build and deployment»، گزینهٔ Source را روی **Deploy from a branch** بگذارید، برنچ `main` و پوشهٔ `/root` را انتخاب و Save کنید.
5. به تب **Settings → Actions → General** بروید و مطمئن شوید «Allow all actions and reusable workflows» فعال است.
6. به تب **Actions** بروید، روی workflow با نام «Update News» کلیک کنید و دکمهٔ **Run workflow** را بزنید تا اولین اجرا دستی انجام شود (بعد از آن، خودش هر ساعت اجرا می‌شود).
7. بعد از چند دقیقه، سایت شما روی این آدرس در دسترس است:
   `https://USERNAME.github.io/malusak/`
   (به‌جای USERNAME نام کاربری گیت‌هاب خودتان را بگذارید)

## اشتراک‌گذاری با چند نفر دیگر
همین لینک `github.io` را برایشان بفرستید؛ چون یک صفحهٔ وب عمومی است، نیازی به دعوت یا عضویت ندارند.

## نکات
- زمان‌بندی Cron در GitHub گاهی چند دقیقه تأخیر دارد (طبیعی است، محدودیت خود GitHub است).
- اگر بیش از ۶۰ روز هیچ فعالیتی (commit) در ریپو نباشد، GitHub ممکن است workflow زمان‌بندی‌شده را غیرفعال کند؛ کافی است یک بار دستی از تب Actions دوباره Run workflow را بزنید تا فعال شود.
- برای افزودن دسته‌های خبری بیشتر، در `scripts/fetch_news.py` به دیکشنری `FEEDS` یک ردیف جدید اضافه کنید و در `index.html` یک بخش (`section`) مشابه بخش‌های موجود بسازید.
- کل این پکیج را می‌توانید به‌جای GitHub Pages، در Cloudflare Pages یا Vercel هم دیپلوی کنید (هر دو رایگان‌اند)؛ فقط باید بخش زمان‌بندی (`cron`) را با Cron Triggers خود آن پلتفرم جایگزین کنید — اما ترکیب GitHub Actions + GitHub Pages ساده‌ترین راه بدون نیاز به تنظیمات اضافه است.
